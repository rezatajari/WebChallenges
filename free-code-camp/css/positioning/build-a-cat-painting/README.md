# Building Cat Painting

**Goal:** Use only HTML and CSS to draw a cat face by combining shapes, gradients, borders, and positioning. Practice building complex visuals without images or SVGs.

## Task

Create a web page that displays a stylized cat painting composed entirely of HTML elements styled with CSS. The design should include:

* **Cat head** shaped with borders, gradients, and border-radius.
* **Ears** built from rotated border triangles with inner ear details.
* **Eyes** with pupils and highlights for a realistic look.
* **Nose** created with a rotated triangle.
* **Mouth** drawn with curved border lines.
* **Whiskers** added using thin rectangles positioned around the mouth.

## Requirements

* Create `index.html` and `styles.css`.
* Use `<div>` elements structured semantically inside a `<main>` container.
* Apply CSS positioning (`absolute`, `relative`) to place facial features correctly.
* Use gradients and border techniques for texture and shape.
* No external images or SVGs — only HTML and CSS.

## Success Checklist

* Cat head appears centered on the page with gradient fill.
* Ears, eyes, nose, mouth, and whiskers are all drawn using CSS.
* All facial features are aligned and proportional.
* No images are used — the painting is entirely HTML & CSS.
* Layout remains consistent on different screen sizes.

# ساخت نقاشی گربه با HTML و CSS

## هدف
استفاده صرفاً از HTML و CSS برای رسم یک صورت گربه با ترکیب اشکال، گرادینت‌ها، حاشیه‌ها و موقعیت‌دهی. هدف این تمرین، تقویت توانایی ساخت تصاویر پیچیده بدون استفاده از تصویر یا SVG است.

---

## وظیفه
یک صفحه وب بسازید که یک نقاشی ساده و استایل‌شده از صورت گربه را نمایش دهد. این نقاشی باید کاملاً با عناصر HTML و استایل‌دهی CSS ساخته شود و شامل موارد زیر باشد:

- سر گربه با استفاده از حاشیه‌ها، گرادینت‌ها و `border-radius`  
- گوش‌ها ساخته‌شده از مثلث‌های چرخیده با جزئیات گوش داخلی  
- چشم‌ها با مردمک و هایلایت برای ظاهر طبیعی‌تر  
- بینی ساخته‌شده با یک مثلث چرخیده  
- دهان رسم‌شده با خطوط منحنی (حاشیه‌ها)  
- سبیل‌ها با مستطیل‌های نازک که اطراف دهان قرار گرفته‌اند  

---

## الزامات
- ایجاد فایل‌های `index.html` و `styles.css`  
- استفاده از عناصر `<div>` به‌صورت ساخت‌یافته داخل یک کانتینر `<main>`  
- استفاده از موقعیت‌دهی CSS (`relative` و `absolute`) برای جای‌دهی دقیق اجزای صورت  
- استفاده از گرادینت‌ها و تکنیک‌های حاشیه برای ایجاد بافت و شکل  
- عدم استفاده از هرگونه تصویر خارجی یا SVG — فقط HTML و CSS  

---

## چک‌لیست موفقیت
- سر گربه در مرکز صفحه قرار داشته باشد و دارای گرادینت باشد  
- گوش‌ها، چشم‌ها، بینی، دهان و سبیل‌ها همگی با CSS رسم شده باشند  
- اجزای صورت به‌درستی تراز شده و تناسب داشته باشند  
- هیچ تصویری استفاده نشده باشد و نقاشی کاملاً با HTML و CSS ساخته شده باشد  
- چیدمان در اندازه‌های مختلف صفحه ثابت و قابل‌قبول باقی بماند

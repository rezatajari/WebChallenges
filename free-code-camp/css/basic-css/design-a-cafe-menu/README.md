# Building Cafe Menu

**Goal:**
Practice structuring a web page with HTML and CSS by creating a café menu layout.

---

## Task

Create a web page that shows a café menu. The page should display menu items grouped by category (e.g. Coffee, Tea, Pastries), with prices, descriptions, and styled layout using CSS.

---

## Requirements

* Create `index.html` and `styles.css` inside this folder.
* Use at least:

  * One heading for the main title of the menu (e.g. “Café Menu”).
  * Subheadings for each category (e.g. “Coffee”, “Tea”, “Pastries”).
  * A list or section of **menu items**, each with:

    * a name
    * a description (short text)
    * a price
* Arrange the menu visually (using CSS) so it looks like a café menu:

  * Style font sizes, spacing, and alignment to be readable.
  * Use colors, borders or background to differentiate categories or items.
  * Make sure the layout is clean and organized (e.g. categories clearly separated).

---

## Success Checklist

* [ ] HTML structure well organized (headings, sections/categories, items)
* [ ] All categories are present with at least one menu item each (name, description, price)
* [ ] CSS applied: styles for spacing, fonts, colors, layout
* [ ] Menu is visually clear and easy to read
* [ ] Page loads correctly (HTML + CSS linked properly)

# ساخت منوی کافه

## هدف

تمرین ساختاردهی یک صفحه وب با استفاده از HTML و CSS از طریق طراحی یک منوی کافه.

---

## وظیفه

یک صفحه وب ایجاد کنید که منوی یک کافه را نمایش دهد.  
این صفحه باید آیتم‌های منو را بر اساس دسته‌بندی (مانند Coffee، Tea، Pastries) گروه‌بندی کند و شامل قیمت، توضیح و چیدمان استایل‌شده با CSS باشد.

---

## الزامات

ایجاد فایل‌های index.html و styles.css در این پوشه.

استفاده از حداقل موارد زیر:

یک heading برای عنوان اصلی منو  
مثال: “Café Menu”

زیرعنوان‌ها برای هر دسته‌بندی  
مثال:  
Coffee  
Tea  
Pastries  

یک لیست یا بخش برای آیتم‌های منو که هر آیتم شامل موارد زیر باشد:

نام آیتم  
توضیح کوتاه  
قیمت  

چیدمان بصری منو با استفاده از CSS به‌طوری که شبیه منوی یک کافه واقعی باشد:

تنظیم اندازه فونت، فاصله‌ها و تراز متن برای خوانایی  
استفاده از رنگ‌ها، حاشیه‌ها یا پس‌زمینه برای تفکیک دسته‌ها یا آیتم‌ها  
تمیز و منظم بودن چیدمان (دسته‌بندی‌ها به‌وضوح از هم جدا باشند)

---

## چک‌لیست موفقیت

ساختار HTML منظم و اصولی پیاده‌سازی شده است  
(headingها، بخش‌ها و آیتم‌ها به‌درستی استفاده شده‌اند)

تمام دسته‌بندی‌ها وجود دارند و هر کدام حداقل یک آیتم دارند  
(شامل نام، توضیح و قیمت)

در CSS به‌درستی اعمال شده است:
فاصله‌ها  
فونت‌ها  
رنگ‌ها  
چیدمان  

منو از نظر بصری واضح، خوانا و منظم است  

صفحه بدون خطا بارگذاری می‌شود  
فایل CSS به‌درستی به HTML لینک شده است

# Registration Form

## Goal

Practice creating a structured and styled registration form using HTML and CSS. Learn how to use different input types, form validation, and CSS styling for layout, spacing, and interactive states.

## Task

Create a web page that displays a registration form for users to enter personal information. Include fields for name, email, password, age, account type, bio, and profile picture upload. Style the form so it is visually appealing and easy to use.

## Requirements

* Create `index.html` and `styles.css` inside this folder
* Include at least the following input types: text, email, password, number, radio, checkbox, file, select, and textarea
* Apply built-in HTML validation using required attributes, min/max values, and patterns
* Organize inputs using fieldsets and labels for accessibility and clarity
* Style the form with CSS to include:

  * Background colors, text colors, borders
  * Consistent spacing and sizing of inputs
  * Inline styling for radio buttons and checkboxes
  * Responsive layout with a maximum and minimum width for the form
* Style the submit button for visibility and usability

## Success Checklist

* Form includes all required input fields and fieldsets
* HTML validation attributes implemented
* CSS styling applied for colors, spacing, and layout
* Inline elements (radio, checkbox) displayed correctly
* Submit button styled and centered
* Form layout is responsive and visually clear
* Optional: hover and focus states added for inputs and submit button

# فرم ثبت‌نام

## هدف
تمرین ساخت یک فرم ثبت‌نام ساخت‌یافته و استایل‌شده با استفاده از HTML و CSS. در این تمرین یاد می‌گیرید چگونه از انواع مختلف ورودی‌ها، اعتبارسنجی داخلی فرم و استایل‌دهی CSS برای چیدمان، فاصله‌گذاری و حالت‌های تعاملی استفاده کنید.

---

## وظیفه
یک صفحه وب ایجاد کنید که یک فرم ثبت‌نام برای ورود اطلاعات شخصی کاربران نمایش دهد. این فرم باید شامل فیلدهایی برای نام، ایمیل، رمز عبور، سن، نوع حساب، بیوگرافی و بارگذاری تصویر پروفایل باشد. فرم را طوری استایل دهید که از نظر بصری جذاب و استفاده از آن آسان باشد.

---

## الزامات
- ایجاد فایل‌های `index.html` و `styles.css` در این پوشه  
- استفاده از حداقل انواع ورودی زیر:
  - متن  
  - ایمیل  
  - رمز عبور  
  - عدد  
  - رادیویی  
  - چک‌باکس  
  - فایل  
  - انتخابی (Select)  
  - ناحیه متنی (Textarea)  
- استفاده از اعتبارسنجی داخلی HTML شامل:
  - ویژگی `required`  
  - مقادیر `min` و `max`  
  - الگوها (pattern)  
- سازمان‌دهی ورودی‌ها با استفاده از `fieldset` و `label` برای دسترس‌پذیری و وضوح بیشتر  
- استایل‌دهی فرم با CSS شامل:
  - رنگ پس‌زمینه، رنگ متن و حاشیه‌ها  
  - فاصله‌گذاری و اندازه یکنواخت برای ورودی‌ها  
  - نمایش درون‌خطی برای دکمه‌های رادیویی و چک‌باکس‌ها  
  - چیدمان واکنش‌گرا با حداقل و حداکثر عرض برای فرم  
  - استایل مناسب برای دکمه ارسال جهت وضوح و کاربری بهتر  

---

## چک‌لیست موفقیت
- فرم شامل تمام فیلدهای ورودی و `fieldset`‌های موردنیاز باشد  
- ویژگی‌های اعتبارسنجی HTML به‌درستی پیاده‌سازی شده باشند  
- استایل‌دهی CSS برای رنگ‌ها، فاصله‌ها و چیدمان اعمال شده باشد  
- عناصر درون‌خطی (رادیویی و چک‌باکس) به‌درستی نمایش داده شوند  
- دکمه ارسال استایل شده و در مرکز قرار گرفته باشد  
- چیدمان فرم واکنش‌گرا و از نظر بصری واضح باشد  
- (اختیاری) حالت‌های hover و focus برای ورودی‌ها و دکمه ارسال اضافه شده باشد

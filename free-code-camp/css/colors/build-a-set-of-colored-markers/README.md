# CSS Color Markers

**Goal:**
Practice applying different CSS color values by creating a set of colored markers. Learn how to use **color names, hex codes, RGB, and HSL** to style elements consistently.

---

## Task

Create a web page that displays three markers with different colors. Each marker should be styled using a different method of setting color values in CSS.

---

## Requirements

* Create `index.html` and `styles.css` inside this folder
* Use at least three markers (e.g., div elements styled to look like markers)
* Apply colors using different methods:

  * **Color keyword** (e.g., `red`, `blue`)
  * **Hexadecimal** (e.g., `#FF0000`)
  * **RGB / RGBA** (e.g., `rgb(0, 255, 0)`)
  * **HSL / HSLA** (e.g., `hsl(240, 100%, 50%)`)
* Style the markers so they resemble actual highlighter markers (e.g., rectangular with rounded edges, centered text if needed)
* Experiment with **background colors, text colors, and complementary color pairs**

---

## Success Checklist

* [ ] HTML structure implemented with three markers
* [ ] CSS applied with at least three different color value types
* [ ] Markers styled (shape, size, spacing) to resemble colored markers
* [ ] Page is visually clear and demonstrates color techniques

# نشانگرهای رنگی با CSS

## هدف
تمرین استفاده از مقادیر مختلف رنگ در CSS با ساخت مجموعه‌ای از نشانگرهای رنگی. در این تمرین یاد می‌گیرید چگونه از نام رنگ‌ها، کدهای هگزادسیمال، RGB و HSL برای استایل‌دهی یکنواخت عناصر استفاده کنید.

---

## وظیفه
یک صفحه وب بسازید که سه نشانگر رنگی مختلف را نمایش دهد. هر نشانگر باید با یک روش متفاوت برای تعیین رنگ در CSS طراحی شده باشد.

---

## الزامات
- ایجاد فایل‌های `index.html` و `styles.css` در این پوشه  
- استفاده از حداقل سه نشانگر (مثلاً عناصر div که شبیه ماژیک طراحی شده‌اند)  
- اعمال رنگ‌ها با روش‌های متفاوت، از جمله:
  - استفاده از نام رنگ‌ها  
  - استفاده از کدهای هگزادسیمال  
  - استفاده از مقادیر RGB یا RGBA  
  - استفاده از مقادیر HSL یا HSLA  
- استایل‌دهی نشانگرها به‌گونه‌ای که شبیه ماژیک یا هایلایتر واقعی باشند  
  (مستطیلی با گوشه‌های گرد و در صورت نیاز متن وسط‌چین)  
- آزمایش با رنگ پس‌زمینه، رنگ متن و ترکیب رنگ‌های مکمل  

---

## چک‌لیست موفقیت
- ساختار HTML شامل سه نشانگر پیاده‌سازی شده باشد  
- در CSS حداقل از سه نوع مقدار رنگ متفاوت استفاده شده باشد  
- نشانگرها از نظر شکل، اندازه و فاصله شبیه ماژیک‌های رنگی باشند  
- صفحه از نظر بصری واضح باشد و تکنیک‌های رنگ را به‌خوبی نمایش دهد

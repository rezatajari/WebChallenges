# Rothko Painting

Goal: Use CSS shapes, colors, shadows, borders, and transforms to create a Rothko-style abstract painting.

---

## Task
Build a painting effect using `<div>` elements and CSS. Apply:
- `background-color` for each colored block  
- `box-shadow` and `filter: blur()` for a painted effect  
- `border-radius` to soften edges  
- `transform: rotate()` for natural imperfections  
- Nested `<div>` structure (`frame` → `canvas` → blocks)  

---

## Requirements
- Create `index.html` and `styles.css`  
- Frame with border, canvas area inside  
- Three colored blocks styled with CSS  
- Use blur, shadows, and rotation for realism  

---

## Success Checklist
- [ ] Frame and canvas layout created  
- [ ] Three abstract blocks styled  
- [ ] Background colors applied  
- [ ] Shadows, blur, and rotation effects added

# نقاشی به سبک روتکو

## هدف
استفاده از شکل‌ها، رنگ‌ها، سایه‌ها، حاشیه‌ها و تبدیل‌ها در CSS برای ساخت یک نقاشی انتزاعی به سبک روتکو.

---

## وظیفه
با استفاده از عناصر `<div>` و استایل‌دهی CSS یک جلوه نقاشی ایجاد کنید. در این پروژه باید از موارد زیر استفاده شود:

- رنگ پس‌زمینه برای هر بلوک رنگی  
- سایه و فیلتر محوشدگی برای ایجاد حس نقاشی‌شده  
- گرد کردن گوشه‌ها برای نرم‌تر شدن لبه‌ها  
- چرخش جزئی برای ایجاد ناهماهنگی طبیعی  
- ساختار تو در تو شامل:
  - قاب  
  - بوم نقاشی  
  - بلوک‌های رنگی  

---

## الزامات
- ایجاد فایل‌های `index.html` و `styles.css`  
- داشتن یک قاب با حاشیه و یک ناحیه بوم در داخل آن  
- استفاده از سه بلوک رنگی که فقط با CSS استایل داده شده‌اند  
- استفاده از محوشدگی، سایه و چرخش برای طبیعی‌تر شدن جلوه  

---

## چک‌لیست موفقیت
- قاب و بوم نقاشی به‌درستی ایجاد شده باشند  
- سه بلوک انتزاعی استایل داده شده باشند  
- رنگ‌های پس‌زمینه به‌درستی اعمال شده باشند  
- افکت‌های سایه، محوشدگی و چرخش اضافه شده باشند

# Build a Hotel Feedback Form

## Objective
Create a **Hotel Feedback Form** to collect customer opinions about their stay. The page should use **semantic HTML** for clarity and accessibility while allowing users to submit feedback easily through a structured form.

---

## Features

### Header Section
- Includes the **page title** (“Hotel Feedback Form”) and a short **introductory message** thanking guests for their stay.  
- Establishes the purpose of the page: collecting feedback.

---

### Personal Information Section
- Implemented using a `<fieldset>` with a `<legend>` for clear grouping.
- Contains the following inputs:
  - **Name** (required text input)
  - **Email** (required email input)
  - **Age** (optional numeric input with `min` and `max` constraints)

# Build a Hotel Feedback Form

## Objective
Create a **Hotel Feedback Form** to collect customer opinions about their stay. The page should use **semantic HTML** for clarity and accessibility while allowing users to submit feedback easily through a structured form.

---

## Features

### Header Section
- Includes the **page title** (“Hotel Feedback Form”) and a short **introductory message** thanking guests for their stay.  
- Establishes the purpose of the page: collecting feedback.

---

### Personal Information Section
- Implemented using a `<fieldset>` with a `<legend>` for clear grouping.
- Contains the following inputs:
  - **Name** (required text input)
  - **Email** (required email input)
  - **Age** (optional numeric input with `min` and `max` constraints)

# ساخت فرم بازخورد هتل

## هدف

ایجاد یک **فرم بازخورد هتل** برای جمع‌آوری نظرات مشتریان دربارهٔ اقامتشان.  
این صفحه باید با استفاده از ساختار **معنایی اچ‌تی‌ام‌ال** طراحی شود تا هم خوانا باشد و هم از نظر دسترسی‌پذیری استاندارد باشد و کاربران بتوانند به‌راحتی بازخورد خود را ارسال کنند.

---

## ویژگی‌ها

### بخش سرصفحه

- شامل عنوان صفحه با متن: **فرم بازخورد هتل**
- یک پیام کوتاه خوشامدگویی و تشکر از مهمانان بابت اقامتشان
- مشخص‌کردن هدف صفحه: **جمع‌آوری بازخورد کاربران**

---

### بخش اطلاعات شخصی

- پیاده‌سازی‌شده با استفاده از **گروه‌بندی معنایی**
- شامل توضیحی برای مشخص‌کردن نوع اطلاعات درخواستی
- ورودی‌های این بخش:
  - **نام** (ورودی متنی و اجباری)
  - **ایمیل** (ورودی ایمیل و اجباری)
  - **سن** (ورودی عددی اختیاری با محدودیت حداقل و حداکثر)

این بخش به شناسایی کاربر و برقراری ارتباط در صورت نیاز کمک می‌کند.

---

### بخش تجربهٔ اقامت در هتل

- استفاده از **دکمه‌های انتخابی** برای مشخص‌کردن تجربهٔ کاربر
- کاربران می‌توانند اعلام کنند که:
  - آیا این **اولین اقامت** آن‌ها در هتل بوده است یا خیر
- این اطلاعات به هتل کمک می‌کند تا تفاوت دیدگاه مشتریان جدید و قدیمی را بررسی کند.

---

### بخش میزان رضایت

- شامل گزینه‌هایی برای ارزیابی سطح رضایت کلی از اقامت
- کاربران می‌توانند نظر خود را از نظر کیفیت خدمات، امکانات و تجربهٔ کلی بیان کنند
- این داده‌ها برای تحلیل کیفیت خدمات بسیار مهم هستند.

---

### بخش نظرات تکمیلی

- یک ورودی متنی بزرگ برای نوشتن:
  - پیشنهادها
  - انتقادات
  - یا هر نظر اضافی دربارهٔ اقامت
- این بخش اختیاری است اما ارزشمندترین بازخوردها معمولاً از این قسمت به‌دست می‌آید.

---

### بخش ارسال فرم

- شامل یک دکمه برای **ارسال بازخورد**
- فرم به‌گونه‌ای طراحی شده که فقط در صورت تکمیل اطلاعات اجباری قابل ارسال باشد
- تجربهٔ کاربری ساده و شفاف برای همهٔ کاربران

---

## چرا این مهم است؟

این تمرین به شما کمک می‌کند:

- با **فرم‌های معنایی** و ساختارمند کار کنید
- ورودی‌های مختلف کاربر را مدیریت کنید
- اصول **دسترسی‌پذیری** را در فرم‌ها رعایت کنید
- داده‌های واقعی کاربران را به‌شکل منظم جمع‌آوری کنید

چنین فرم‌هایی در وب‌سایت‌های واقعی هتل‌ها، فروشگاه‌ها و خدمات آنلاین نقش کلیدی دارند و کیفیت تجربهٔ کاربر را بهبود می‌دهند.

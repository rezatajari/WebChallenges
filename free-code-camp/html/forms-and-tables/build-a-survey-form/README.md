# Build a Survey Form

## Objective
Create a survey form that collects user information and preferences, following the challenge requirements. The form should be functional, user-friendly, and styled with a background image.

## Features
- Page title (`<h1>`) and description (`<p>`) introducing the form.
- Input fields for:
  - Name
  - Email
  - Age (number with min/max validation)
- Radio buttons for gender selection.
- Dropdown to select a field of interest.
- Checkboxes for hobbies or preferences.
- Textarea for additional comments.
- Submit button.
- Responsive form layout centered on the page.
- Background image with semi-transparent form container for readability.
- Input fields styled for clarity and user-friendliness.

## How to Use
1. Clone or download the project.
2. Open `index.html` in a web browser.
3. Fill out the form fields and submit.

## Technologies
- HTML5
- CSS3
- No JavaScript (vanilla HTML/CSS implementation)

## Notes
- All inputs use proper validation where applicable.
- Form container and inputs use `box-sizing: border-box` to prevent overflow.
- The form is responsive and centered using Flexbox.

# ساخت فرم نظرسنجی

## هدف

ایجاد یک **فرم نظرسنجی** برای جمع‌آوری اطلاعات و ترجیحات کاربران مطابق با الزامات چالش.  
فرم باید **کاربردی، کاربرپسند** بوده و با استفاده از **تصویر پس‌زمینه** طراحی شود.

---

## ویژگی‌ها

- عنوان صفحه با استفاده از **تیتر اصلی**
- یک **توضیح کوتاه** برای معرفی هدف فرم
- فیلدهای ورودی شامل:
  - **نام**
  - **ایمیل**
  - **سن** (عدد با محدودیت حداقل و حداکثر)
- **دکمه‌های انتخابی** برای تعیین جنسیت
- **فهرست کشویی** برای انتخاب حوزهٔ علاقه‌مندی
- **چک‌باکس‌ها** برای انتخاب سرگرمی‌ها یا ترجیحات
- **کادر متنی بزرگ** برای نوشتن توضیحات یا نظرات اضافی
- **دکمهٔ ارسال فرم**
- چیدمان **واکنش‌گرا** و قرارگیری فرم در مرکز صفحه
- تصویر پس‌زمینه به همراه **باکس نیمه‌شفاف فرم** برای خوانایی بهتر
- طراحی ورودی‌ها به‌صورت واضح و کاربرپسند

---

## نحوهٔ استفاده

1. پروژه را دریافت یا کلون کنید  
2. فایل اصلی را در مرورگر وب باز کنید  
3. فیلدهای فرم را تکمیل کرده و آن را ارسال کنید  

---

## فناوری‌های استفاده‌شده

- اچ‌تی‌ام‌ال نسخهٔ پنج
- سی‌اس‌اس نسخهٔ سه
- بدون استفاده از جاوااسکریپت (فقط اچ‌تی‌ام‌ال و سی‌اس‌اس ساده)

---

## نکات

- تمام ورودی‌ها در صورت نیاز دارای **اعتبارسنجی مناسب** هستند
- کانتینر فرم و ورودی‌ها از **مدل جعبه‌ای یکسان** استفاده می‌کنند تا از بیرون‌زدگی جلوگیری شود
- فرم با استفاده از **فلکس‌باکس** به‌صورت مرکزی و واکنش‌گرا طراحی شده است

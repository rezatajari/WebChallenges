# Build an Event Hub Page

## Objective
Create a personal event hub page to showcase upcoming and past events. The page should be organized, visually clear, and easy to navigate, using semantic HTML elements to structure content.

## Features
- **Header Section**: 
  - Page title introducing the hub (`Event Hub`).
  - Navigation menu linking to different sections (`Upcoming Events`, `Past Events`).

- **Upcoming Events Section**: 
  - Section with `id="upcoming-events"`.
  - Multiple articles, each representing an upcoming event.
  - Each article contains:
    - Event title (`<h3>`).
    - Event description (`<p>`).
    - Optional date for the event.

- **Past Events Section**: 
  - Section with `id="past-events"`.
  - Multiple articles, each representing a past event.
  - Each article contains:
    - Event title (`<h3>`).
    - Event description (`<p>`).
    - Optional date for the event.
    - Event image with descriptive `alt` text.

## How to Use
1. Open the `index.html` file in a web browser.
2. Use the navigation menu to jump to the Upcoming Events or Past Events sections.
3. Browse upcoming events or revisit past events with images and descriptions.

## Technologies
- HTML5
- Semantic HTML elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<img>`)

## Notes
- The page is structured semantically to improve accessibility and readability.
- Navigation uses an unordered list of anchor links for smooth section jumps.
- Event images include descriptive `alt` text for accessibility.
- Dates and descriptions are customizable for real-world events.

# ساخت صفحه مرکز رویدادها (Event Hub)

## هدف

ایجاد یک صفحهٔ شخصی **مرکز رویدادها** برای نمایش رویدادهای آینده و گذشته.  
این صفحه باید منظم، از نظر بصری واضح و برای ناوبری آسان باشد و از عناصر معنایی HTML برای ساختاربندی محتوا استفاده کند.

---

## ویژگی‌ها

### بخش سربرگ

- عنوان صفحه برای معرفی مرکز رویدادها  
  **Event Hub**
- منوی ناوبری برای دسترسی سریع به بخش‌ها:
  - رویدادهای آینده
  - رویدادهای گذشته

---

### بخش رویدادهای آینده

- یک بخش با شناسه `upcoming-events`
- شامل چندین مقاله که هرکدام نمایانگر یک رویداد آینده هستند
- هر مقاله شامل:
  - عنوان رویداد
  - توضیح رویداد
  - تاریخ رویداد (اختیاری)

---

### بخش رویدادهای گذشته

- یک بخش با شناسه `past-events`
- شامل چندین مقاله که هرکدام نمایانگر یک رویداد گذشته هستند
- هر مقاله شامل:
  - عنوان رویداد
  - توضیح رویداد
  - تاریخ رویداد (اختیاری)
  - تصویر رویداد به‌همراه متن جایگزین توصیفی

---

## نحوهٔ استفاده

1. فایل `index.html` را در یک مرورگر وب باز کنید  
2. با استفاده از منوی ناوبری به بخش رویدادهای آینده یا گذشته بروید  
3. رویدادهای آینده را بررسی کنید یا رویدادهای گذشته را همراه با تصاویر و توضیحات مرور کنید  

---

## فناوری‌های استفاده‌شده

- HTML5
- عناصر معنایی HTML:
  - سربرگ
  - ناوبری
  - محتوای اصلی
  - بخش‌ها
  - مقاله‌ها
  - تصویر

---

## نکات

- ساختار معنایی صفحه باعث بهبود **دسترس‌پذیری و خوانایی** می‌شود  
- ناوبری با استفاده از فهرست بدون ترتیب و لینک‌های لنگری انجام می‌شود  
- تصاویر رویدادها دارای متن جایگزین توصیفی هستند تا برای کاربران ابزارهای کمکی قابل‌دسترس باشند  
- تاریخ‌ها و توضیحات به‌راحتی قابل ویرایش برای رویدادهای واقعی هستند

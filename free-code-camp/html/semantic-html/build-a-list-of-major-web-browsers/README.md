# Build a List of Major Web Browsers

## Objective
Create a webpage that lists major web browsers along with brief descriptions using **semantic HTML definition lists**. The page organizes browser names and descriptions clearly for readability and accessibility.

---

## Features

### Header Section
- Main heading (`<h1>`) displays the title: **“List of Major Web Browsers”**.

---

### Definition List (`<dl>`)
- Uses semantic elements `<dl>`, `<dt>`, and `<dd>` to pair browser names with their descriptions.  
- Each entry includes:
  - **Browser Name** (`<dt>`)  
  - **Description** (`<dd>`)

Example entries:
1. **Google Chrome**  
   - Free web browser developed by Google, first released in 2008.
2. **Firefox**  
   - Free web browser developed by Mozilla Corporation, first created in 2004.
3. **Safari**  
   - Developed by Apple; default browser for iPhone, iPad, and Mac devices.
4. **Brave**  
   - Free browser based on Chromium, first released in 2016.
5. **Arc**  
   - Free Chromium-based browser released in 2023 by The Browser Company.

---

## How to Use
1. Open the HTML file in a web browser.  
2. Browse the list to learn about major web browsers and their key features.  
3. Use the semantic structure for easy reference or as a template for adding more browsers.

---

## Technologies
- **HTML5**
- Semantic elements:
  - `<dl>` for definition lists
  - `<dt>` for terms (browser names)
  - `<dd>` for definitions (descriptions)

---

## Notes
- The page uses **semantic HTML** to pair terms with definitions, enhancing accessibility and readability.  
- Ideal for educational content, documentation, or reference guides.  
- The structure can easily be extended with additional browsers or links to their official websites.

---

## Challenge Tasks
- Add **links** to each browser’s official website in the `<dd>` element.  
- Include the browser **release year** as a separate `<dd>` line for better clarity.  
- Apply **CSS styling** to visually distinguish browser names from descriptions.  
- Add icons or logos next to each browser name using `<img>` elements.

# فهرست مرورگرهای اصلی وب

## هدف

ایجاد یک **صفحه وب** که مرورگرهای اصلی وب را به‌همراه توضیح کوتاه دربارهٔ هرکدام نمایش دهد.  
در این تمرین از **فهرست تعریفی معنایی** استفاده می‌شود تا نام مرورگرها و توضیحات آن‌ها به‌صورت واضح، خوانا و دسترس‌پذیر سازمان‌دهی شوند.

---

## ویژگی‌ها

### بخش سربرگ

- عنوان اصلی صفحه که با یک تیتر سطح یک نمایش داده می‌شود و متن آن:  
  **«فهرست مرورگرهای اصلی وب»**

---

### فهرست تعریفی

- استفاده از ساختار معنایی فهرست تعریفی برای نمایش داده‌ها  
- هر مرورگر شامل دو بخش است:
  - **نام مرورگر**
  - **توضیح کوتاه دربارهٔ آن**

#### نمونه مرورگرها

- **گوگل کروم**  
  مرورگر وب رایگان توسعه‌داده‌شده توسط گوگل که نخستین‌بار در سال ۲۰۰۸ منتشر شد.

- **فایرفاکس**  
  مرورگر وب رایگان توسعه‌داده‌شده توسط بنیاد موزیلا که اولین نسخهٔ آن در سال ۲۰۰۴ ارائه شد.

- **سافاری**  
  مرورگر توسعه‌داده‌شده توسط اپل و مرورگر پیش‌فرض دستگاه‌های آیفون، آیپد و مک.

- **بریو**  
  مرورگر رایگان مبتنی بر کرومیوم که نخستین‌بار در سال ۲۰۱۶ منتشر شد.

- **آرک**  
  مرورگر رایگان مبتنی بر کرومیوم که در سال ۲۰۲۳ توسط شرکت «شرکت مرورگر» عرضه شد.

---

## نحوهٔ استفاده

1. فایل اچ‌تی‌ام‌ال را در یک مرورگر وب باز کنید  
2. فهرست مرورگرها را مرور کنید و با ویژگی‌های هرکدام آشنا شوید  
3. از این ساختار به‌عنوان الگو برای افزودن مرورگرهای بیشتر استفاده کنید  

---

## فناوری‌های استفاده‌شده

- اچ‌تی‌ام‌ال نسخهٔ پنج  
- عناصر معنایی:
  - فهرست تعریفی  
  - عنوان‌ها و توضیحات مرتبط  

---

## نکات

- استفاده از ساختار معنایی باعث افزایش **خوانایی و دسترس‌پذیری** صفحه می‌شود  
- این قالب برای محتوای آموزشی، مستندات و راهنماها بسیار مناسب است  
- ساختار صفحه به‌راحتی قابل گسترش بوده و می‌توان مرورگرهای جدید یا پیوندهای تکمیلی اضافه کرد  

---

## تمرین‌های پیشنهادی

- افزودن پیوند به وب‌سایت رسمی هر مرورگر در بخش توضیحات  
- نمایش سال انتشار هر مرورگر در یک خط جداگانه  
- اعمال استایل‌های ظاهری برای متمایز کردن نام مرورگر از توضیح آن  
- اضافه‌کردن آیکون یا لوگوی هر مرورگر در کنار نام آن

# Build a Cat Blog Page

## Objective
Create a personal blog page to showcase posts about Mr. Whiskers, the beloved cat, along with an About section and contact information. The page should be organized, readable, and easy to navigate.

## Features
- **Header Section**: 
  - Page title introducing the blog.
  - Featured image of Mr. Whiskers with a caption.
  - Navigation menu linking to different sections (`About`, `Posts`, `Contact`).

- **About Section**: 
  - Introduction of the author and her relationship with Mr. Whiskers.
  - Brief description highlighting the cat’s personality.

- **Posts Section**:
  - Multiple blog articles with titles and paragraphs describing Mr. Whiskers' experiences (e.g., first day home, first bath, birthday party).
  - Each post includes multiple paragraphs for detailed storytelling.

- **Contact Section**:
  - Phone number wrapped in a clickable link for calling.
  - Email address wrapped in a clickable link for sending email.

## How to Use
1. Open the `index.html` file in a web browser.
2. Use the navigation menu to jump between sections.
3. Read posts, learn about the author and Mr. Whiskers, or contact via phone or email.

## Technologies
- HTML5

## Notes
- The page is structured semantically with `<header>`, `<main>`, `<section>`, `<article>`, and `<footer>`.
- Images use `<figure>` and `<figcaption>` for better accessibility and semantic meaning.
- Navigation uses an unordered list of anchor links for smooth section navigation.
- Contact details use proper clickable links (`tel:` for phone, `mailto:` for email).

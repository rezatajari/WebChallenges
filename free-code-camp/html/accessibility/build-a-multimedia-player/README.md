# Build a Multimedia Player

Build a multimedia player that presents an audio track, a video, and a readable transcript. Your final project should be functionally similar to the reference example while maintaining your own layout and style.

## Objective

Complete all user stories listed below. Your project must satisfy every requirement to pass the associated tests.

## User Stories

1. You should include an h1 element that serves as the main title of the page.
2. You should create three section elements.
3. Inside the first section element, you should include an h2 element representing the title of the audio track.
4. Below this h2 element, you should include an audio element containing both a controls attribute and an aria-label attribute.
5. Inside the audio element, you should include a source element with a valid src attribute pointing to an audio file and a type attribute.
   You may use this URL if you choose:
   [https://cdn.freecodecamp.org/curriculum/js-music-player/sailing-away.mp3](https://cdn.freecodecamp.org/curriculum/js-music-player/sailing-away.mp3)
6. Inside the second section element, you should include an h2 element representing the title of the video.
7. Below this h2 element, you should include a video element containing controls, width, and aria-label attributes.
8. Inside the video element, you should include a source element with a valid src attribute pointing to a video file and a type attribute.
   You may use this URL if you choose:
   [https://cdn.freecodecamp.org/curriculum/labs/what-is-the-map-method-and-how-does-it-work.mp4](https://cdn.freecodecamp.org/curriculum/labs/what-is-the-map-method-and-how-does-it-work.mp4)
9. Under the source element, you should include a track element. This track element must contain:

   * a src attribute pointing to a subtitles file
   * a kind attribute
   * an srclang attribute
   * a label attribute
10. Inside the third section element, you should include an h2 element describing the section, such as Transcript.
11. Below this h2 element, you should include a p element containing the transcript text for the video.

## Requirements

You may design the layout however you like. Ensure each user story is met exactly so your project passes all automated tests.

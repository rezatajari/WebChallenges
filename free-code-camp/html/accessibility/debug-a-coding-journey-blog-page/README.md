# Debug a Coding Journey Blog Page

## Overview

You are given two versions of an HTML document:

* One **incorrect version** containing structural, semantic, and heading-level issues.
* One **correct version** showing how the document should be fixed using proper semantic tags and logical heading hierarchy.

Your task is to study both versions and identify **what was wrong** in the incorrect version and **why the correct version fixes it**.

---

## Challenge Instructions

### 1. Identify Incorrect Usage

Examine the incorrect version and detect errors such as:

* Wrong heading levels (e.g., multiple `<h1>` used inside content sections).
* Missing semantic elements such as `<nav>`, `<main>`, `<article>`, `<footer>`.
* Navigation section not wrapped in appropriate structure.
* Content sections not separated properly.
* Contact section presented outside any semantic container.
* Lack of accessible structure.

Write down each issue clearly.

---

### 2. Explain Each Fix

For every issue you identify in the incorrect version:

* Describe **why** it is incorrect.
* Describe **how the correct version solves the problem**, for example:

  * Using one main `<h1>` for the page title.
  * Replacing generic `<div>` containers with meaningful semantic elements.
  * Improving accessibility through proper heading order and document landmarks.

---

### 3. Write a Summary

At the end, include a short summary of what proper HTML structure should look like:

* Page landmarks
* Logical heading hierarchy
* Accessibility considerations
* When to use semantic tags instead of `<div>`

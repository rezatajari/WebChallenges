# Debug a Coding Journey Blog Page

## Overview

You are given two versions of an HTML document:

* One **incorrect version** containing structural, semantic, and heading-level issues.
* One **correct version** showing how the document should be fixed using proper semantic tags and logical heading hierarchy.

Your task is to study both versions and identify **what was wrong** in the incorrect version and **why the correct version fixes it**.

---

## Challenge Instructions

### 1. Identify Incorrect Usage

Examine the incorrect version and detect errors such as:

* Wrong heading levels (e.g., multiple `<h1>` used inside content sections).
* Missing semantic elements such as `<nav>`, `<main>`, `<article>`, `<footer>`.
* Navigation section not wrapped in appropriate structure.
* Content sections not separated properly.
* Contact section presented outside any semantic container.
* Lack of accessible structure.

Write down each issue clearly.

---

### 2. Explain Each Fix

For every issue you identify in the incorrect version:

* Describe **why** it is incorrect.
* Describe **how the correct version solves the problem**, for example:

  * Using one main `<h1>` for the page title.
  * Replacing generic `<div>` containers with meaningful semantic elements.
  * Improving accessibility through proper heading order and document landmarks.

---

### 3. Write a Summary

At the end, include a short summary of what proper HTML structure should look like:

* Page landmarks
* Logical heading hierarchy
* Accessibility considerations
* When to use semantic tags instead of `<div>`

# اشکال‌زدایی یک صفحهٔ وبلاگ مسیر برنامه‌نویسی

## نمای کلی  
در این چالش دو نسخه از یک سند HTML به شما داده شده است:

• یک نسخهٔ نادرست که دارای مشکلات ساختاری، معنایی و سطح‌بندی تیترهاست  
• یک نسخهٔ صحیح که نشان می‌دهد این سند چگونه باید با تگ‌های معنایی و سلسله‌مراتب درست اصلاح شود  

وظیفهٔ شما این است که هر دو نسخه را بررسی کنید و تشخیص دهید:

• چه چیزی در نسخهٔ نادرست اشتباه بوده  
• و چرا نسخهٔ صحیح مشکل را برطرف می‌کند  

---

## دستورالعمل‌های چالش

### ۱. شناسایی استفادهٔ نادرست  
نسخهٔ نادرست را بررسی کنید و خطاهایی مانند موارد زیر را پیدا کنید:

• سطح‌بندی اشتباه تیترها (مثلاً استفادهٔ متعدد از `<h1>` داخل بخش‌های محتوا)  
• نبود تگ‌های معنایی مانند `<nav>`, `<main>`, `<article>`, `<footer>`  
• نبود ساختار مناسب برای بخش ناوبری  
• جدا نشدن مناسب بخش‌های محتوا  
• قرار گرفتن بخش تماس خارج از هر ساختار معنایی  
• نبود ساختار قابل‌دسترسی برای کاربران  

هر مشکل را به‌صورت واضح و جداگانه بنویسید.

---

### ۲. توضیح هر اصلاح  
برای هر خطایی که در نسخهٔ نادرست پیدا می‌کنید:

• توضیح دهید چرا اشتباه است  
• توضیح دهید نسخهٔ صحیح چگونه آن را برطرف می‌کند  

برای مثال:

• استفاده از یک `<h1>` اصلی برای عنوان صفحه  
• جایگزینی `<div>`های بی‌معنی با تگ‌های معنایی مناسب  
• بهبود دسترس‌پذیری با رعایت ترتیب تیترها و ایجاد نقاط تعیین‌کنندهٔ صفحه (landmarks)  

---

### ۳. نوشتن یک خلاصه  
در پایان، یک خلاصهٔ کوتاه از اینکه ساختار صحیح HTML چگونه باید باشد، بنویسید. شامل:

• نقاط اصلی ساختار صفحه (Page Landmarks)  
• سلسله‌مراتب منطقی تیترها  
• ملاحظات دسترس‌پذیری  
• زمان مناسب برای استفاده از تگ‌های معنایی به‌جای `<div>`

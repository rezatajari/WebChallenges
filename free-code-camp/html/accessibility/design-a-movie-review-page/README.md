# Design a Movie Review Page

Build a simple movie review page that is functionally similar to the example project. Do not copy the design directly; apply your own structure and style.

## Objective

Complete all user stories below to finish the challenge. Your project should pass all related tests.

## User Stories

1. You should have a main element in the page.
2. Inside the main element, you should include an h1 element representing the movie title.
3. Below the h1, include an img element showing the movie cover. The img element must have meaningful alt text that describes the image.
   You may use this image if you prefer:
   [https://cdn.freecodecamp.org/curriculum/labs/rise-beyond-2.png](https://cdn.freecodecamp.org/curriculum/labs/rise-beyond-2.png)
4. You should include a p element that contains a short movie description.
5. You should include another p element dedicated to the movie rating. This rating paragraph must contain the following items in the exact order:

   * A strong element with the text Movie Rating:.
   * A span element that has the aria-hidden attribute set to true. This span must contain the visual star rating.
   * A numerical rating inside parentheses following the span (example: 9.2/10).
6. You should include an h2 element with the text Cast Members.
7. You should include a ul element.
8. Inside the ul, you should create several li elements. Each li must contain:

   * A strong element showing the actor’s name.
   * The text as followed by the character's name.
     Example: James Holloway as Ethan Carter

## Requirements

Your layout, styling, and structure are up to you, but all user stories must be implemented exactly to meet the test conditions.

# طراحی یک صفحهٔ نقد فیلم

یک صفحهٔ سادهٔ نقد فیلم بسازید که از نظر عملکرد مشابه پروژهٔ نمونه باشد.  
طرح را کپی نکنید؛ ساختار و سبک دلخواه خودتان را اعمال کنید.

## هدف

تمام *User Story*‌های زیر را پیاده‌سازی کنید تا چالش تکمیل شود.  
پروژهٔ شما باید تمام تست‌ها را با موفقیت بگذراند.

---

## User Stories

• باید یک المنت `<main>` در صفحه وجود داشته باشد.  

• داخل المنت اصلی، باید یک تیتر `<h1>` وجود داشته باشد که عنوان فیلم را نمایش می‌دهد.  

• زیر عنوان، باید یک تصویر `<img>` قرار دهید که کاور فیلم را نشان دهد.  
  این تصویر باید **متن جایگزین (alt)** معنادار داشته باشد.  
  می‌توانید از این تصویر استفاده کنید:  
  https://cdn.freecodecamp.org/curriculum/labs/rise-beyond-2.png  

• باید یک پاراگراف `<p>` شامل توضیح کوتاه دربارهٔ فیلم قرار دهید.  

• باید یک پاراگراف دیگر مخصوص امتیاز فیلم اضافه کنید.  
  این پاراگراف باید دقیقاً شامل موارد زیر و به همین ترتیب باشد:  
  • یک المنت `<strong>` با متن دقیق: «Movie Rating:»  
  • یک المنت `<span>` که دارای `aria-hidden="true"` باشد و شامل ستاره‌های بصری باشد  
  • یک امتیاز عددی داخل پرانتز بعد از span (مثال: ‎(9.2/10)‎ )  

• باید یک تیتر `<h2>` با متن «Cast Members» اضافه کنید.  

• باید یک لیست `<ul>` ایجاد کنید.  

• داخل لیست، چندین `<li>` قرار دهید که هرکدام شامل موارد زیر باشند:  
  • یک المنت `<strong>` که نام بازیگر را نمایش می‌دهد  
  • سپس متن «as» به‌همراه نام شخصیت  
    مثال: James Holloway as Ethan Carter
